# Release Notes

All notable Stable Captions releases are tracked here, newest first.

## 1.1.0 — Unreleased

Prepared for Chrome, Firefox, and Safari on macOS.

### Added

- HackerTube support through YouTube's privacy-enhanced embedded player.
- `Shift+L` switches between the video's original captions and your preferred language. Languages chosen in YouTube's subtitles menu are remembered locally.
- Boring caption style: a full line of up to seven words in your system font, with optional word highlighting.
- `Shift+K` and `Shift+J` move captions up or down for the current video. The position resets on the next video and is never saved.

### Improved

- Emoji render in the system emoji font without losing caption timing or highlighting.
- Simpler popup previews show all three styles as still captions that follow the current display settings.
- Lower caption memory retention.
- More reliable caption loading when moving between videos.
- Better Short caption layout on zoomed pages.

## 1.0.0 — 2026-10-03

Initial stable release for Chrome, Firefox, and Safari on macOS.

- Stable, short caption chunks on YouTube.
- Frosted and Short caption styles.
- Clean verbatim filtering for fillers and repeated words.
- Adjustable text size, background, and word highlighting.
- Caption and display keyboard shortcuts.

## 0.1.0 Firefox test build — 2026-10-03

Unsigned Firefox 128+ prerelease build for temporary installation and testing through `about:debugging`.
